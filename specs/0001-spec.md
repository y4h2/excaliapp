# ExcaliApp 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
ExcaliApp 是一个简洁的桌面应用程序，用于本地管理和编辑 Excalidraw 文件（.excalidraw）。应用采用 Wails 框架开发，提供原生桌面体验。

### 1.2 目标用户
- 需要本地管理和编辑 Excalidraw 文件的个人用户
- 希望脱离浏览器环境使用 Excalidraw 的用户
- 需要批量管理多个 .excalidraw 文件的用户

### 1.3 核心价值
- **本地化管理**：无需联网，所有文件存储在本地
- **简洁高效**：专注于文件编辑，无复杂功能
- **原生体验**：桌面应用的流畅性和便捷性

## 2. 核心功能

### 2.1 目录管理

#### 2.1.1 选择工作目录
**功能描述**：用户可以选择一个本地目录作为工作目录，应用会扫描该目录下的所有 .excalidraw 文件。

**用户交互**：
- 应用启动时，如果之前已选择过目录，则自动加载上次的工作目录
- 如果是首次使用，提示用户选择工作目录
- 提供"打开目录"功能，允许用户随时切换工作目录

**技术要求**：
- 使用 Wails 的文件系统 API 实现目录选择对话框
- 持久化保存上次选择的目录路径

#### 2.1.2 文件列表展示
**功能描述**：在侧边栏中展示工作目录下的所有 .excalidraw 文件。

**显示内容**：
- 文件名（去除 .excalidraw 后缀显示）
- 文件修改时间（可选）
- 当前打开的文件高亮显示

**交互行为**：
- 支持文件列表的滚动浏览
- 点击文件名即可打开对应文件

### 2.2 文件编辑

#### 2.2.1 Excalidraw 编辑器集成
**功能描述**：在主屏幕区域集成 Excalidraw SDK，提供完整的绘图编辑功能。

**技术要求**：
- 使用官方 Excalidraw SDK
- 完整支持 Excalidraw 的所有绘图功能（绘制、文本、图形、连接线等）
- 支持快捷键操作

#### 2.2.2 文件切换
**功能描述**：用户在侧边栏点击不同文件时，主屏幕切换显示对应的 Excalidraw 内容。

**交互行为**：
- 点击新文件时，加载并显示该文件内容
- 如果当前文件有未保存的修改，自动触发保存

**技术要求**：
- 解析 .excalidraw 文件（JSON 格式）
- 将数据传递给 Excalidraw SDK 进行渲染

### 2.3 自动保存

#### 2.3.1 保存触发条件
**功能描述**：在以下情况下自动保存当前编辑的文件：

1. **切换文件时**：用户在侧边栏选择其他文件时
2. **应用失去焦点时**：用户切换到其他应用或窗口时（可选）
3. **定时保存**：每隔一定时间自动保存（建议 30 秒或 1 分钟）

**技术要求**：
- 监听编辑器内容变化
- 实现防抖机制，避免频繁写入文件
- 保存时将 Excalidraw 数据序列化为 JSON 格式

#### 2.3.2 保存状态提示
**功能描述**：向用户展示当前文件的保存状态。

**显示方式**：
- 状态栏显示"已保存"或"保存中..."
- 文件列表中未保存的文件显示标记（如圆点）

### 2.4 文件操作

#### 2.4.1 新建文件
**功能描述**：在当前工作目录下创建新的 .excalidraw 文件。

**用户交互**：
- 提供"新建文件"按钮或菜单项
- 创建文件时使用默认命名（如"未命名-1.excalidraw"）
- 新建后自动在主屏幕打开该文件

#### 2.4.2 重命名文件
**功能描述**：允许用户重命名文件。

**用户交互**：
- 右键点击文件或通过菜单触发重命名
- 弹出输入框，输入新文件名
- 验证文件名合法性（不重复、不包含非法字符）

#### 2.4.3 删除文件
**功能描述**：删除选中的文件。

**用户交互**：
- 右键点击文件或通过菜单触发删除
- 弹出确认对话框
- 确认后从文件系统删除文件，并从侧边栏移除

**安全机制**：
- 删除前必须二次确认
- 可选：提供回收站功能（将文件移至系统回收站而非直接删除）

## 3. 界面设计

### 3.1 整体布局

```
┌─────────────────────────────────────────────┐
│  菜单栏（原生）                              │
├───────────┬─────────────────────────────────┤
│           │                                 │
│  侧边栏   │      主屏幕（Excalidraw）       │
│           │                                 │
│  - 文件1  │                                 │
│  - 文件2  │                                 │
│  - 文件3  │                                 │
│           │                                 │
│           │                                 │
│           │                                 │
│           │                                 │
├───────────┴─────────────────────────────────┤
│  状态栏（保存状态、文件信息）                │
└─────────────────────────────────────────────┘
```

### 3.2 侧边栏设计

**宽度**：200-250px（可调整）
**功能区域**：
- 顶部：工作目录路径显示 + "打开目录"按钮
- 中间：文件列表（可滚动）
- 底部：新建文件按钮

**文件列表项**：
- 文件图标（Excalidraw 图标）
- 文件名
- 选中状态高亮
- 未保存标记（圆点）

### 3.3 主屏幕设计

**功能**：
- 完整集成 Excalidraw 编辑器
- 顶部工具栏（Excalidraw 自带）
- 画布区域占据所有可用空间

### 3.4 状态栏设计

**显示内容**：
- 左侧：当前文件名
- 中间：保存状态（"已保存" / "保存中..."）
- 右侧：文件路径或其他元信息

## 4. 技术规格

### 4.1 技术栈

- **框架**：Wails v2
- **前端**：React + TypeScript + Vite
- **样式**：TailwindCSS
- **编辑器**：Excalidraw SDK
- **后端**：Go（Wails 集成）

### 4.2 文件格式

**.excalidraw 文件结构**：
```json
{
  "type": "excalidraw",
  "version": 2,
  "source": "https://excalidraw.com",
  "elements": [...],
  "appState": {...},
  "files": {...}
}
```

### 4.3 数据持久化

**应用配置**：
- 上次打开的工作目录路径
- 窗口大小和位置
- 侧边栏展开/折叠状态

**存储方式**：
- 使用 Wails 的应用数据目录
- JSON 格式配置文件

### 4.4 跨平台支持

- **macOS**：完整支持
- **Windows**：完整支持
- **Linux**：完整支持

## 5. 非功能性需求

### 5.1 性能要求

- 应用启动时间：< 2 秒
- 文件切换响应时间：< 500 毫秒
- 大文件（包含 100+ 元素）编辑流畅，无明显卡顿

### 5.2 稳定性要求

- 自动保存机制确保数据不丢失
- 异常情况下（崩溃、断电）能恢复上次编辑状态
- 文件操作（读写、删除）提供错误处理和用户提示

### 5.3 用户体验要求

- 界面简洁，无多余元素
- 快捷键支持（新建、保存、切换文件等）
- 原生菜单栏集成（File、Edit、View 等）
