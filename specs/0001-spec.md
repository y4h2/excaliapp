# 产品需求文档 (PRD)
# Excalidraw 编辑器桌面应用

## 1. 产品概述

### 1.1 产品定位
一款轻量级桌面应用，用于查看和编辑 Excalidraw 文件。应用提供侧边栏文件浏览器和主画布区域，实现 Excalidraw 文件的无缝管理和编辑。

### 1.2 目标用户
- 使用 Excalidraw 图表的个人用户
- 需要快速访问绘图文件的设计师、开发者和项目管理者
- 偏好桌面应用而非网页工具的用户

### 1.3 核心价值
- **本地文件管理**：直接访问本地 Excalidraw 文件，无需云依赖
- **无缝编辑**：原生桌面体验，文件切换即时响应
- **自动保存保护**：切换文件时自动保存，防止数据丢失
- **简洁工作流**：无需注册、团队或企业功能 - 即开即用

## 2. 核心功能

### 2.1 文件管理
- **目录选择**：用户可选择包含 Excalidraw 文件的目录
- **文件发现**：自动扫描并显示选中目录中的所有 `.excalidraw` 文件
- **最近目录**：记住上次使用的目录，应用启动时自动打开
- **文件列表**：侧边栏显示所有发现的 Excalidraw 文件，包含：
  - 文件名称
  - 最后修改日期
  - 未保存更改的视觉指示器

### 2.2 Excalidraw 集成
- **文件加载**：在主画布区域打开并显示 Excalidraw 文件
- **完整编辑**：使用 Excalidraw SDK 提供完整的编辑功能
- **实时画布**：交互式绘图、形状、文本和所有 Excalidraw 功能
- **文件格式**：支持标准 `.excalidraw` 文件格式

### 2.3 自动保存系统
- **变更检测**：实时监控文件修改
- **自动保存**：在以下情况自动保存更改：
  - 用户切换到侧边栏中的其他文件
  - 应用失去焦点或被最小化
  - 一段时间无操作后（可配置，默认5秒）
- **保存指示器**：显示保存状态的视觉反馈
- **冲突解决**：处理外部修改文件的情况

### 2.4 用户界面
- **布局**：侧边栏和主画布的双面板设计
- **菜单栏**：原生应用菜单栏支持，包含文件操作
  - **文件菜单**：提供目录选择和文件操作功能
    - "打开目录"：选择新的 Excalidraw 文件目录
    - "关闭"：关闭当前目录
    - "退出"：退出应用
- **侧边栏**：左侧可折叠文件浏览器
- **主画布**：右侧完整 Excalidraw 编辑器
- **响应式**：适配不同窗口大小
- **简洁设计**：最小化、无干扰的界面

## 3. 技术要求

### 3.1 技术栈
- **框架**：Wails v2.x 跨平台桌面应用
- **前端**：React/TypeScript 配合 TailwindCSS
- **Excalidraw**：集成 Excalidraw SDK/组件
- **存储**：本地文件系统访问
- **状态管理**：React Context 或类似方案管理应用状态

### 3.2 平台支持
- **主要**：macOS（符合人机界面指南）
- **次要**：Windows 和 Linux 支持
- **架构**：各平台原生桌面应用

### 3.3 文件系统集成
- **目录监控**：监控选中目录的新增/删除文件
- **文件操作**：读取、写入和保存 `.excalidraw` 文件
- **权限处理**：优雅处理文件系统权限
- **性能**：高效的文件列表和过滤

### 3.4 菜单栏集成
- **原生菜单**：使用 Wails 原生菜单 API 创建应用菜单栏
- **跨平台**：适配 macOS、Windows 和 Linux 平台的菜单规范
- **快捷键**：支持标准快捷键（如 Cmd/Ctrl+O 打开目录）
- **菜单状态**：动态更新菜单项状态（启用/禁用）

## 4. 用户体验流程

### 4.1 首次启动
1. 应用打开目录选择对话框
2. 用户选择包含 Excalidraw 文件的目录
3. 侧边栏填充发现的文件
4. 第一个文件在主画布中自动打开
5. 用户可立即开始编辑

### 4.2 后续启动
1. 应用记住上次使用的目录
2. 自动扫描并加载该目录中的文件
3. 打开最后编辑的文件（如果可用）
4. 用户可通过菜单栏或工具栏更改目录

### 4.3 切换目录（通过菜单栏）
1. 用户点击菜单栏"文件"菜单
2. 选择"打开目录"选项（或使用快捷键 Cmd/Ctrl+O）
3. 弹出目录选择对话框
4. 如果当前文件有未保存更改 → 自动保存
5. 新目录扫描并加载文件到侧边栏
6. 自动打开新目录中的第一个文件

### 4.4 文件切换
1. 用户点击侧边栏中的不同文件
2. 如果当前文件有未保存更改 → 自动保存
3. 新文件在主画布中加载
4. 保留前一个文件的更改

## 5. 非功能性需求

### 5.1 性能要求
- **启动时间**：完全加载状态 < 2秒
- **文件切换**：文件间切换（包括自动保存）< 500ms
- **画布渲染**：流畅的 60fps 交互
- **内存使用**：典型使用情况下 < 200MB

### 5.2 可靠性
- **数据完整性**：崩溃或强制关闭时无数据丢失
- **错误处理**：优雅处理损坏文件
- **自动恢复**：意外关闭后恢复未保存的更改
- **文件备份**：保存前可选文件备份

### 5.3 可用性
- **无障碍**：支持键盘导航
- **国际化**：支持各种语言的文件名
- **错误消息**：清晰、可操作的错误消息
- **帮助系统**：基本应用内帮助和工具提示
